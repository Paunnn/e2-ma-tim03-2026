# Slagalica

Android aplikacija razvijena u Jetpack Compose i Kotlinu, sa Firebase backendom (Authentication, Firestore, Cloud Messaging).

## Pokretanje

1. Otvoriti projekat u Android Studiju
2. Sačekati da se Gradle sinhronizuje
3. Priključiti uređaj ili pokrenuti emulator
4. Pokrenuti aplikaciju (Run ili Shift + F10)
